# 🌟 Flex Box Project

This is a simple project built while learning **CSS Flexbox**, part of my web development journey. It demonstrates how flex properties work and how they can be used to create responsive layouts.

## 📚 About the Project

The project includes examples of:

- `flex-direction`
- `justify-content`
- `align-items`
- `flex-wrap`
- `gap`, `order`, `align-self`, and more

These concepts are applied to create layout structures like:
- Centered items
- Navigation bars
- Card grids
- Responsive containers
